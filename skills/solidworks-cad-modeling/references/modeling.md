# 从图纸到原生 SolidWorks 模型

## 任务划分

读图先确定零件边界、视图方向、单位、基准、剖面、重复关系和加工/装配意图。对有冲突的尺寸列出来源；照片透视和像素比例不能覆盖标注尺寸。只有图片时需要至少一个已知尺寸，未给出的背面、壁厚或连接结构应注明。

常见顺序是主轮廓 → 主体拉伸/旋转 → 切除/开孔 → 筋和凸台 → 阵列 → 圆角/倒角。轴对称件优先旋转，板金件保留钣金与展开信息，装配体分别建立零件并添加配合。根据实际形状调整顺序；复杂曲面分阶段处理，先验证关键截面。

## 用户默认要求：原生特征与真实装配

2026-10-20 用户指定，后续 SW 建模默认执行：

- 尽可能使用 SW 原生命令和对应 API，保留有意义的草图、尺寸、拉伸、切除、旋转、扫描、孔、圆角、阵列与装配配合。MCP、COM 和宏只是调用方式；批量写入不透明实体不能替代本可建立的原生特征。
- 建模前列出实际零件/子装配、重复规格、数量、连接界面及支撑关系。一个可独立制造或采购的零件对应一个主零件文件；阀门、法兰、垫片、紧固件、管段、支架等按实际产品结构拆分，不按颜色或类别塞进一个 SLDPRT。
- 普通零件应为连续实体。零件内出现无物理联系的分离实体或悬浮物体时，应修正遗漏的连接几何或拆分成独立零件装配，不能通过隐藏实体、改视角或强行合并来掩盖。真实焊件等工艺允许的多实体结构须符合其制造语义并具有实际连接。
- 相同几何、规格和材料的零件使用同一 SLDPRT，多次插入或使用组件阵列。文件清单/BOM 中记录该主文件和实例数量。不同长度、孔型或材料按实际差异区分，必要时使用经过核验的配置，避免仅按外包络尺寸错误复用。
- 先建立基准/固定组件，其余组件按实际接口添加同心、重合、距离、角度等配合。插入坐标可以给初始位置，但不能替代所需配合；不能把所有组件固定来伪装装配完成。运动件保留设计需要的自由度，并记录其意义。
- 管路对接要核对轴线、端面间隙、法兰/垫片厚度与连接件；支架要与基础和被支撑对象实际连接。视觉接近、相互穿插或被固定在空间中均不能单独证明连接成立。非接触配合、间隙和运动连接按真实设计验证，不强求所有零部件布尔连成一个实体。

## 连接和装配验收

1. 读取各普通零件的实体数量，检查是否存在意外分离实体；对真实多实体结构列出其工艺依据、连接关系和预期实体数。
2. 检查零件特征树及关键尺寸；不能仅凭实体外形判断是否保留了可编辑的原生建模过程。
3. 读取组件文件路径/配置/实例数量，确认相同规格重复件指向同一主文件；检查装配引用完整。
4. 重建并检查配合错误、抑制状态、欠约束及意外自由度。读取关键接口的轴线、端面距离/间隙和安装位置，核对支撑与连接关系；保留设计需要的自由度并说明。
5. 在普通装配状态检查正交视图、等轴测及必要剖视；同时核对干涉与必要净空。故意的压配合等按设计说明判断，不能把所有干涉都机械删除；零干涉也不能证明没有悬空或遗漏连接。
6. 保存、关闭本轮文件并重新打开装配，核对配合和外部引用仍有效。交付 SLDASM 及其引用零件，附重复件数量、关键连接和未验证项。只有明确要求爆炸图时才额外提供爆炸状态，不能把分散摆放当成正常装配完成。

## API 与文件细节

- API 几何以米、弧度表达；用户尺寸先统一单位再转换。STEP/STL/图纸显示单位分别验收。
- 中英文 SW 模板名称不同。按类型遍历基准特征或记录实际名称，不默认字符串 `Front Plane` 一定存在。
- 检查新建文档、草图实体、特征创建的返回值；重建失败即停止。保存前清空选择，防止只导出选中的面或实体。
- 输出到新的、由当前任务指定的路径，保存前检查文件存在性。不要以自动保存方式覆盖用户原模型。
- 给真实设计添加尺寸和关系；样例只有坐标不意味着完成了完全约束。原生草图/特征树、全参数化和制造可交付是不同验收要求。
- `.bas` 是可检查源代码；`.swp` 是保存后的 VBA 项目。不能靠更改后缀转换。
- `RunMacro2` 的返回值和错误码只表示调用情况。宏内部应另行报告几何、重建、保存和导出结果。
- 本包对简单零件保留兼容旧版本的 `IModelDocExtension.SaveAs` 示例。它在 2022 文档中已标记为旧接口；复杂装配复制或带外部引用的保存需按目标版本改用相应新接口，不能照搬简单零件示例。

## 失败与交付

保留最先失败的 API、参数、软件版本和输出。先修复该失败再继续，避免在空实体或错误选集上叠加后续操作。连接异常时先确认注册、打开状态、模态对话框、用户与权限；不默认需要 MCP。

验收覆盖关键尺寸、孔/槽数量与位置、壁厚、实体数、重建、外部引用、保存重开和交换格式重导入。交付说明应区分“只生成了宏”“宏已运行”“模型与导出已验收”。若软件不可用，交付源代码和下一步运行说明，并明确原生模型尚未生成。
